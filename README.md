# Terminal Portfolio - mifdev0

A terminal-style personal portfolio website with a dark theme and retro aesthetic.

## Features

- 🖥️ Terminal-style interface with macOS window controls
- ⌨️ Interactive command-line interface
- 🎨 Dark theme with green accent colors
- 📱 Fully responsive design
- ✨ Typing animations for all outputs
- 🎯 Data-driven from JSON file
- 🔄 Command history with arrow keys

## Commands

- `/help` - Show all available commands
- `/profile` - View profile information
- `/projects` - Browse projects with links
- `/experience` - View work experience timeline
- `/skills` - See tech stack by category
- `/music` - Current playlist on Spotify
- `/contact` - Get in touch
- `/clear` - Clear terminal output

## Tech Stack

- HTML5
- CSS3 (with CSS Variables)
- Vanilla JavaScript
- Lucide Icons (via CDN)

## Setup

1. Clone this repository
2. Add your images to the `assets/` folder:
   - `avatar.jpg` - Your profile picture
   - `projects/` - Project thumbnails
   - `music/` - Playlist cover
3. Edit `data.json` with your information
4. Open `index.html` in a browser

## Customization

All content is stored in `data.json`. Update this file to customize:
- Profile information
- Projects
- Work experience
- Skills
- Music playlist
- Contact information

## Design

Based on the "Root Access" design system with:
- Digital Brutalist aesthetic
- High-contrast minimalism
- CRT scanline effect
- Terminal green accent color (#4be277)
- Space Grotesk font family
